# Two Sum - Python

This project contains my solution to the classic Two Sum problem using Python.

## Problem
Given a list of integers and a target number, return the indices of the two numbers that add up to the target.

## Solution
I used a dictionary (hashmap) to store previously seen numbers and their indices, allowing the solution to run in O(n) time complexity.

## Example
Input:
[2, 7, 11, 15]
Target:
9

Output:
[0, 1]

## Concepts Used
- Python classes
- Functions
- Dictionaries / Hashmaps
- enumerate()
- Time complexity optimization
